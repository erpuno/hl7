## About the Project

The ** Public Health Center (PHC)** is developing the **Governmental Statistical Warehouse (GSW)** — a
secure, high-performance, cloud-based platform for collecting, storing, processing and analyzing aggregated statistical healthcare data across Ukraine.  

The warehouse supports:  
- Evidence-based health policy decisions  
- Epidemiological surveillance  
- Healthcare resource planning and allocation  

We are looking for an experienced **DevOps Engineer** to design, build and operate the reliable,
secure and scalable infrastructure underpinning this national-level system.

## Statement of Work – Main Responsibilities

### 1. Core Scope of Work
- Design & implement end-to-end CI/CD pipelines
- Automate infrastructure provisioning and configuration (IaC)
- Ensure high availability, disaster recovery and scalability
- Implement comprehensive monitoring, logging and alerting
- Harden security posture (encryption, access control, auditability)
- Collaborate closely with data engineers, backend developers and security specialists

### 2. Key Deliverables
- Automated CI/CD pipelines (dev → test → staging → prod)
- Terraform / OpenTofu (or equivalent) infrastructure code for compliant cloud environments
- Kubernetes-based (or equivalent) orchestration setup
- Centralized logging, metrics and tracing (Prometheus + Grafana + Loki / ELK / Tempo / similar)
- Security baseline implementation & documentation (aligned with Ukrainian state requirements)
- Backup & disaster recovery procedures
- Cost-optimization dashboard / reports
- Knowledge transfer sessions and internal documentation

### 3. Indicative Timeline & Milestones
- **Months 1–2**   Infrastructure assessment & toolchain selection
- **Months 3–6**   Core pipelines, IaC, container platform, initial environments
- **Months 7–9**   Security hardening, observability stack, performance testing
- **Months 10–12**  Production readiness, load testing, handover & documentation
- **Ongoing**      Support, incident response, continuous improvement

### 4. Required SLAs & Quality Gates
- Infrastructure uptime target: **≥ 99.9%**
- Critical incident acknowledgment: **≤ 30 minutes**
- Deployment frequency goal: **≥ 1 production release per 2 weeks**
- 100% compliance with Ukrainian data protection & state IT security regulations
